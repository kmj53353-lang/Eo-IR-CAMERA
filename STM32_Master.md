# 📖 용어 사전 — 약어 전체 풀이 & 한줄 정의

> 이 문서에 등장하는 모든 약어·전문용어 가나다/알파벳 순 정리.

---

## A

| 약어 | 풀어쓰기 | 한줄 정의 |
|------|----------|-----------|
| **ADC** | Analog-to-Digital Converter | 아날로그 → 디지털 변환. STM32 내장 12bit SAR ADC. V_ref=3.3V → LSB=0.8mV. |
| **AHB** | Advanced High-performance Bus | ARM 고속 버스. STM32 코어·DMA·메모리 연결. 최대 CPU 클럭(168MHz). |
| **APB** | Advanced Peripheral Bus | ARM 주변장치 버스. APB1(≤42MHz), APB2(≤84MHz). UART/SPI/I2C/타이머 연결. |
| **ARM** | Advanced RISC Machine | 감소명령셋(RISC) 기반 프로세서 아키텍처. STM32는 ARM Cortex-M 코어 사용. |
| **ATSM** | ARM Thumb-2 Instruction Set | 16/32bit 혼합 명령어셋. 코드 밀도와 성능 동시 확보. |

---

## B

| 약어 | 풀어쓰기 | 한줄 정의 |
|------|----------|-----------|
| **BSRR** | Bit Set/Reset Register | GPIO 원자적 세트/리셋 레지스터. 상위 16bit=리셋, 하위 16bit=세트. Read-Modify-Write 불필요. |
| **BSP** | Board Support Package | 보드 지원 패키지. 특정 하드웨어에 맞춘 드라이버·초기화 코드 묶음. |
| **부트로더(Bootloader)** | Bootloader | MCU 전원 투입 시 가장 먼저 실행되는 코드. 플래시 프로그래밍, DFU, 점프 담당. |

---

## C

| 약어 | 풀어쓰기 | 한줄 정의 |
|------|----------|-----------|
| **CCR** | Capture/Compare Register | 타이머 캡처·비교 레지스터. PWM 듀티비 설정(출력) 또는 입력 캡처값 저장(입력). |
| **CRC** | Cyclic Redundancy Check | 순환중복검사. 데이터 오류 검출용 체크섬. STM32 하드웨어 CRC 내장. |
| **Cortex-M** | ARM Cortex-M Series | ARM의 마이크로컨트롤러용 프로세서 계열. M0/M0+/M3/M4/M7/M33 등. STM32F4=M4. |
| **CMSIS** | Cortex Microcontroller Software Interface Standard | ARM 표준 소프트웨어 인터페이스. 코어 레지스터·인터럽트 접근 표준화. |
| **CSR** | Control/Status Register | 제어·상태 레지스터. 주변장치 동작 설정 및 상태 확인용. |

## D

| 약어 | 풀어쓰기 | 한줄 정의 |
|------|----------|-----------|
| **DAC** | Digital-to-Analog Converter | 디지털 → 아날로그 변환. STM32 내장 12bit DAC. 기준전압 출력 또는 신호 생성. |
| **DMA** | Direct Memory Access | 직접 메모리 접근. CPU 개입 없이 주변장치 ↔ 메모리 데이터 자동 이송. CPU 부하 감소. |
| **DWT** | Data Watchpoint and Trace | 데이터 워치포인트·추적 유닛. 사이클 카운터(DWT_CYCCNT)로 μs 단위 실행 시간 측정. |

## E

| 약어 | 풀어쓰기 | 한줄 정의 |
|------|----------|-----------|

| **ETM** | Embedded Trace Macrocell | 임베디드 트레이스 매크로셀. 실시간 명령어 트레이스. J-Trace로 사용. |

## F

| **FPU** | Floating Point Unit | 부동소수점 연산 유닛. Cortex-M4/M7에 내장. PID 연산·삼각함수 하드웨어 가속. |
| **FSMC** | Flexible Static Memory Controller | 유연 정적 메모리 컨트롤러. 외부 SRAM·NOR Flash·LCD 인터페이스. |

## G

| **GPIOx_ODR** | Output Data Register | GPIO 출력 데이터 레지스터. 비트 단위로 핀 출력 레벨 설정. |

# PART 0 — STM32란 무엇인가? 왜 이 MCU인가?

```
┌──────────────────────────────────────────────────────────────────────────────────────┐
│  ★ PART 0 블록 설명 — 이 파트가 왜 있는가?                                             │
│                                                                                      │
│  STM32 = ST마이크로일렉트로닉스의 ARM Cortex-M 기반 32bit MCU 패밀리                  │
│  "MCU 하나에 CPU + 메모리 + 모든 주변장치가 다 들어있는 단일 칩"                      │
│                                                                                      │
│  열영상 카메라·PTZ 시스템에서 STM32가 하는 일:                                        │
│  ① PWM 생성 → H-Bridge 구동 → 스털링 냉각기 피스톤 왕복 → 77K 냉각                 │
│  ② 엔코더 카운팅(QEI) → 팬틸트 현재 각도 측정                                       │
│  ③ PID 연산(FPU) → PWM 듀티 조정 → 팬틸트 목표각 추적                              │
│  ④ RS-422 UART 수신 → C2 명령 파싱 → 팬틸트 목표값 업데이트                        │
│  ⑤ SPI 통신 → FPGA에서 ADC 데이터 수신 / 설정값 전달                               │
│  ⑥ ADC 내장 → 전류 감지(H-Bridge 과전류 보호) / 온도 모니터링                       │
│                                                                                      │
│  왜 STM32F407인가?                                                                   │
│  ARM Cortex-M4 + FPU → PID 부동소수점 연산 1클럭                                   │
│  168MHz → PWM 20kHz 듀티 분해능 8400 스텝 → 팬틸트 정밀 속도 제어                  │
│  다중 타이머(14개) → 냉각기 PWM + 팬 PWM + 틸트 PWM + 엔코더 × 2 동시              │
│  DMA → UART/SPI 데이터 CPU 개입 없이 자동 처리 → PID 루프 지연 없음                │
└──────────────────────────────────────────────────────────────────────────────────────┘
```

## STM32 패밀리 전체 지도

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│  STM32 패밀리 선택 가이드 (열영상 카메라 PTZ 제어 관점)                                   │
│                                                                                          │
│  패밀리      코어        최대클럭   FPU   Flash   SRAM   PTZ제어 적합성                   │
```

## 2-2. PWM 주파수·분해능 계산

```
┌────────────────────────────────────────────────────────────────────────────────────┐
│  PWM 파라미터 계산 (열영상 카메라 적용)                                              │
│                                                                                    │
│  PWM 주파수 공식:                                                                   │
│  f_PWM = f_TIM / ((PSC+1) × (ARR+1))                                             │
│                                                                                    │
│  f_TIM (TIM1, APB2 계열) = PCLK2 × 2 = 84MHz × 2 = 168MHz                      │
│                                                                                    │
│  ① 스털링 냉각기 PWM: 50Hz 사인파 근사                                             │
│  목표: 50Hz, 분해능 최대화                                                          │
│  PSC = 0, ARR = 168,000,000/50 - 1 = 3,359,999  ← 32bit TIM2/5만 가능!          │
│  → TIM3(16bit) 사용 시: PSC=9, ARR=335,999 → f=168M/(10×336000)=50Hz ✓          │
│  듀티 분해능: 1/336000 = 0.0003%                                                   │
│                                                                                    │
│  ② H-Bridge Pan 모터 PWM: 20kHz (가청 주파수 이상)                                │
│  f_TIM=168MHz, PSC=0, ARR=?                                                       │
│  ARR = 168,000,000/20,000 - 1 = 8,399                                            │
│  듀티 설정: CCR1 = 0~8399 (0~100%)                                                │
│  분해능: 1/8400 = 0.012% → 팬 모터 속도 0.012% 단위 제어 ✓                       │
│                                                                                    │
│  ③ 서보 PWM: 50Hz (1~2ms 펄스)                                                    │
│  PSC=167, ARR=9999 → f=168M/(168×10000)=100Hz (서보는 50~100Hz)                 │
│  1ms 펄스 = CCR = 100 / 서보 0°                                                   │
│  2ms 펄스 = CCR = 200 / 서보 180°                                                 │
│                                                                                    │
│  타이머 클럭 확인 핵심:                                                              │
│  TIM1/8/9/10/11 → APB2 계열 → 168MHz                                             │
│  TIM2~7/12~14   → APB1 계열 → 84MHz (ARR 계산 기준이 다름!)                      │
```

## 4-1. 타이머 내부 구조 완전도

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│  STM32 타이머 내부 블록도 (범용 TIM 기준)                                                 │
│                                                                                          │
│  클럭 소스 ─────────────────────────────────────────────────────────────────────────    │
│  ┌──────────────────────────────────────────────────────────────────────────────────┐   │
│  │  Internal clock (CK_INT) ← APB 클럭 × 2                                         │   │
│  │  External TIx pin        ← 외부 클럭 또는 엔코더                                  │   │
│  │  ITRx (다른 타이머 연결)                                                           │   │
│  └─────────────────────────────┬────────────────────────────────────────────────────┘   │
│                                ▼                                                          │
│  ┌───────────────────────────────────────────────────────────────────────────────────┐   │
│  │  프리스케일러 (PSC, 16bit)                                                          │   │
│  │  f_CK_CNT = f_CK_INT / (PSC + 1)                                                  │   │
│  │  예: f_CK_INT=168MHz, PSC=0 → f_CK_CNT=168MHz (1카운트=5.95ns)                  │   │
│  └─────────────────────────────┬─────────────────────────────────────────────────────┘  │
│                                ▼                                                          │
│  ┌───────────────────────────────────────────────────────────────────────────────────┐   │
│  │  카운터 (CNT, 16bit 또는 32bit)                                                    │   │
│  │  Up 카운팅: 0 → ARR → 0 (overflow → Update 이벤트 → 인터럽트)                    │   │
│  │  Center-aligned: 0 → ARR → 0 → ARR ... (PWM에서 데드타임 자동)                  │   │
│  └─────────────────────────────┬─────────────────────────────────────────────────────┘  │
│                                ▼                                                          │
│  ┌───────────────────────────────────────────────────────────────────────────────────┐   │
│  │  Auto-Reload Register (ARR) — PWM 주기 결정                                        │   │
│  │  Update 이벤트: CNT가 ARR 도달 → CNT=0 → 인터럽트 가능                            │   │
│  └─────────────────────────────┬─────────────────────────────────────────────────────┘  │
│                                ▼                                                          │
│  ┌───────────────────────────────────────────────────────────────────────────────────┐   │
│  │  캡처/비교 채널 × 4 (CHx)                                                          │   │
│  │                                                                                   │   │
│  │  PWM 출력 모드:  CNT < CCR → 핀=HIGH / CNT ≥ CCR → 핀=LOW (Mode1)               │   │
│  │  듀티비 = CCR / ARR × 100%                                                        │   │
│  │                                                                                   │   │
│  │  입력 캡처 모드: 외부 엣지 감지 → CNT값을 CCR에 저장 → 인터럽트                   │   │
│  │  → 엣지 간격으로 주파수·듀티 측정                                                  │   │
│  └───────────────────────────────────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

## 🔴 열영상 카메라 연결 — 통신 오류가 열영상 시스템에 미치는 영향

# PART 7 — 인터럽트·DMA: CPU 없이 어떻게 데이터가 흐르는가


## 7-1. NVIC 인터럽트 처리 흐름

```
┌────────────────────────────────────────────────────────────────────────────────────┐
│  인터럽트 발생 → 처리 → 복귀 전체 흐름                                              │
│                                                                                    │
│  정상 실행 (main 루프):                                                              │
│  ... A B C D E F G H ...                                                           │
│                 ↑                                                                  │
│                 │ TIM1 Update IRQ 발생                                              │
│                 │                                                                  │
│  하드웨어 자동:  │                                                                  │
│  ① PC, PSR, R0~R3, R12, LR → 스택에 자동 push (8 레지스터)                       │
│  ② NVIC가 TIM1_IRQHandler 주소로 PC 변경                                          │
│                 │                                                                  │
│  ISR 실행:      ▼                                                                  │
│  TIM1_UP_TIM10_IRQHandler()                                                        │
│  {                                                                                  │
│      __HAL_TIM_CLEAR_IT(&htim1, TIM_IT_UPDATE); // 인터럽트 플래그 클리어 必須    │
│      // PID 계산                                                                    │
│      error = target - encoder_count;                                               │
│      pwm_duty = PID_Calculate(error);                                              │
│      __HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, pwm_duty);                      │
│  }                                                                                  │
│                 │                                                                  │
│  하드웨어 자동:  │                                                                  │
│  ③ 스택에서 8 레지스터 자동 pop → 원래 PC로 복귀                                  │
│                 ↓                                                                  │
│  ... D E F G H I J ... (아무 일도 없었던 것처럼)                                  │
│                                                                                    │
│  ★ ISR에서 절대 금지:                                                               │
```

```
│  hdma_usart1_rx.Init.Mode                = DMA_CIRCULAR;   // 순환 모드!               │
│  hdma_usart1_rx.Init.Priority            = DMA_PRIORITY_HIGH;                          │
│                                                                                          │
```

## 8-1. H-Bridge 4가지 동작 상태 STM32 코드

## 9-1. PID 완전 구현 (STM32 FPU 활용)

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│  STM32F407 FPU PID 완전 구현 코드                                                         │
│                                                                                          │
│  typedef struct {                                                                         │
│      float Kp, Ki, Kd;       // PID 게인                                                │
│      float integral;          // 적분 누산값                                             │
│      float prev_error;        // 이전 오차 (미분용)                                     │
│      float integral_max;      // 적분 와인드업 방지 상한                                 │
│      float output_max;        // 출력 클램핑 (PWM 범위)                                 │
│      float dt;                // 샘플링 주기 (1/1000 = 0.001s)                         │
│  } PID_t;                                                                                │
│                                                                                          │
│  // 광운대 PTZ 실험값 (튜닝 후):                                                         │
│  PID_t pan_pid = {                                                                       │
│      .Kp           = 120.0f,   // P게인: 오차 1° → 출력 120 (ARR=8399 기준)          │
│      .Ki           = 8.0f,     // I게인: 중력·마찰 정적 오차 보상                       │
│      .Kd           = 5.0f,     // D게인: 오버슈트 감쇠                                  │
│      .integral_max = 2000.0f,  // 적분 와인드업 방지                                    │
│      .output_max   = 8399.0f,  // PWM 최대값                                           │
│      .dt           = 0.001f,   // 1kHz                                                  │
│  };                                                                                      │
│                                                                                          │
│  float PID_Update(PID_t *pid, float setpoint, float measurement) {                      │
│      float error = setpoint - measurement;                                               │
│                                                                                          │
│      // P항 (즉각 반응)                                                                  │
│      float P = pid->Kp * error;                                                         │
│                                                                                          │
│      // I항 (정적 오차 제거, 와인드업 방지)                                              │
│      pid->integral += error * pid->dt;                                                  │
│      if (pid->integral >  pid->integral_max) pid->integral =  pid->integral_max;       │
│      if (pid->integral < -pid->integral_max) pid->integral = -pid->integral_max;       │
│      float I = pid->Ki * pid->integral;                                                 │
│                                                                                          │
│      // D항 (진동 억제)                                                                  │
│      float derivative = (error - pid->prev_error) / pid->dt;                           │
│      float D = pid->Kd * derivative;                                                    │
│      pid->prev_error = error;                                                           │
│                                                                                          │
│      // 출력 합산 + 클램핑                                                               │
│      float output = P + I + D;                                                          │
│      if (output >  pid->output_max) output =  pid->output_max;                         │
│      if (output < -pid->output_max) output = -pid->output_max;                         │
│                                                                                          │
│      return output;                                                                      │
│  }                                                                                       │
│                                                                                          │
│  // TIM6 1kHz ISR에서 호출:                                                              │
│  void TIM6_DAC_IRQHandler(void) {                                                        │
│      __HAL_TIM_CLEAR_IT(&htim6, TIM_IT_UPDATE);                                         │
│                                                                                          │
│      // 엔코더 읽기                                                                       │
│      float pan_angle  = Encoder_GetAngle(&htim2);   // 도 단위                         │
│      float tilt_angle = Encoder_GetAngle(&htim5);                                       │
│                                                                                          │
│      // PID 계산 (FPU: 각 연산 1클럭)                                                   │
│      float pan_output  = PID_Update(&pan_pid,  pan_target,  pan_angle);                │
│      float tilt_output = PID_Update(&tilt_pid, tilt_target, tilt_angle);               │
│                                                                                          │
│      // PWM 적용 (방향 + 크기 분리)                                                     │
│      Motor_Apply(MOTOR_PAN,  pan_output);                                               │
│      Motor_Apply(MOTOR_TILT, tilt_output);                                              │
│  }                                                                                       │
```

## 10-2. 플래시 읽기·쓰기 (NUC 계수 저장)

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│  STM32F407 내부 플래시 — NUC 계수 저장 구현                                               │
│                                                                                          │
│  Flash 레이아웃 (1MB):                                                                   │
│  섹터0:  16KB  (0x08000000) ← 부트로더/벡터테이블                                       │
│  섹터1:  16KB  (0x08004000)                                                              │
│  섹터2:  16KB  (0x08008000) ← 사용자 코드                                               │
│  섹터3:  16KB  (0x0800C000)                                                              │
│  섹터4:  64KB  (0x08010000)                                                              │
│  섹터5: 128KB  (0x08020000) ← NUC 계수 저장 (섹터5 전용)                               │
│  섹터6: 128KB  (0x08040000)                                                              │
│  섹터7: 128KB  (0x08060000)                                                              │
│                                                                                          │
│  NUC 계수 구조 (FPGA에서 수신 후 저장):                                                  │
│  typedef struct {                                                                         │
│      float gain[640][512];    // 이득 계수 (320KB)                                     │
│      float offset[640][512];  // 오프셋 계수 (320KB)                                   │
│      uint32_t magic;          // 0xDEADBEEF (유효성 확인)                              │
│      uint32_t crc;            // CRC32                                                  │
│  } NUC_Data_t;                // 총 ~640KB → 섹터5+6+7 사용                           │
│                                                                                          │
│  Flash 쓰기 (소거 필수):                                                                  │
│  HAL_FLASH_Unlock();                                                                     │
│  FLASH_EraseInitTypeDef erase = {                                                        │
│      .TypeErase = FLASH_TYPEERASE_SECTORS,                                               │
│      .Sector    = FLASH_SECTOR_5,                                                        │
│      .NbSectors = 3,    // 섹터5,6,7                                                   │
│      .VoltageRange = FLASH_VOLTAGE_RANGE_3  // 2.7~3.6V                               │
│  };                                                                                      │
│  uint32_t err;                                                                           │
│  HAL_FLASHEx_Erase(&erase, &err);                                                       │
│                                                                                          │
│  // 32bit 단위로 쓰기                                                                    │
│  uint32_t *src = (uint32_t *)&nuc_data;                                                 │
│  uint32_t  dst = 0x08020000;                                                             │
│  for (int i = 0; i < sizeof(NUC_Data_t)/4; i++) {                                     │
│      HAL_FLASH_Program(FLASH_TYPEPROGRAM_WORD, dst, src[i]);                            │
│      dst += 4;                                                                           │
│  }                                                                                       │
│  HAL_FLASH_Lock();                                                                       │
│                                                                                          │
│  Flash 읽기 (포인터 캐스팅으로 직접 접근):                                               │
│  NUC_Data_t *nuc = (NUC_Data_t *)0x08020000;                                          │
│  if (nuc->magic == 0xDEADBEEF && CRC32_Check(nuc)) {                                  │
│      // 유효한 NUC 계수 → FPGA로 전달                                                  │
│      SPI_Send_NUC(nuc);                                                                 │
│  }                                                                                       │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
```

```
│                                                                                          │
│  Step 1: H-Bridge 출력 전압 측정 (DMM)                                                  │

│  → 0V = H-Bridge 미구동 → Step 2로                                                     │
│  → 전압 있음 = 모터 자체 문제 → 코일 저항 측정 (단선 여부)                             │
│                                                                                          │
│  Step 2: 게이트드라이버 EN 핀 전압 측정                                                  │
│  → 0V = STM32 GPIO 미출력 → Step 3로                                                   │
│  → 3.3V = 게이트드라이버 자체 불량 → IC 교체                                          │
│                                                                                          │
│  Step 3: STM32 TIM1 CH1 핀 오실로스코프 측정                                            │

│  → 구형파(HIGH/LOW) = GPIO 출력 모드 → AF 설정 확인                                   │
│     GPIO_InitStruct.Alternate = GPIO_AF1_TIM1; 누락 확인                              │

│                                                                                          │
│  Step 4: J-Link Watch에서 PID 출력 확인                                                 │
│  pan_target ≠ pan_angle? → 오차 있음 → PID 출력 확인                                 │
│  → PID 출력 = 0 → Kp=0 초기화 오류 확인                                             │
│  pan_target = 0, pan_angle = 0 → 목표값 미수신 → Step 5로                            │
│                                                                                          │
│  Step 5: UART 수신 확인                                                                  │
```

```
│  과전류 감시 불가 → MOSFET 소손 위험 → 장비 파괴                                        │
│                                                                                          │
│  STM32 = 열영상 카메라 시스템의 신경계                                                    │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```
