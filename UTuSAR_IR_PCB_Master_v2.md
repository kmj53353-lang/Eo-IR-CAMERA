## 1-B. WHAT : MOSFET 완전 모델

```
MOSFET 물리 구조 (NMOS 단면):

  Gate
   │
  [산화막 SiO₂  tox~수nm]
   │
  ┌─────────────────────────────────────────────┐
  │                p-형 기판                      │
  │   n+소스             n+드레인                 │
  │  ┌───┐ ←채널(L)→  ┌───┐                    │
  │  │   │             │   │                    │
  └──┴───┴─────────────┴───┴────────────────────┘
  S                                          D

  핵심 파라미터:
  μn  = 전자 이동도 ~450 cm²/Vs (NMOS)
  Cox = ε0·εox / tox  [F/m²]
  W/L = 채널 폭/길이 비 (설계 변수)
  Vth = 문턱전압 (공정 파라미터, 통상 0.3~0.7V)

동작 영역별 수식 (전체):

  차단 영역 (VGS < Vth):
  ┌─────────────────────────────────────────────┐
  │  ID = 0                                     │
  │  → 스위치 OFF, 픽셀 미선택 상태             │
  └─────────────────────────────────────────────┘

  선형(Triode) 영역 (VGS > Vth, VDS < VGS-Vth):
  ┌─────────────────────────────────────────────┐
  │  ID = μn·Cox·(W/L)·[(VGS-Vth)·VDS          │
  │                      - VDS²/2]              │
  │  → 저저항 스위치로 동작                     │
  │  → Ron = 1/(μn·Cox·W/L·(VGS-Vth))         │
  │  → 리셋 MOSFET, Row Select MOSFET 동작점  │
  └─────────────────────────────────────────────┘

  포화 영역 (VGS > Vth, VDS ≥ VGS-Vth):
  ┌─────────────────────────────────────────────┐
  │  ID = (μn·Cox·W/2L)·(VGS-Vth)²·(1+λVDS)  │
  │                                             │
  │  λ = 채널길이변조 계수 (1/VA)              │
  │  VA = Early 전압 (~10~100V)               │
  │                                             │
  │  → 전류원으로 동작                         │
  │  → CTIA M1, 꼬리 전류원 MOSFET 동작점    │
  └─────────────────────────────────────────────┘

  준-포화(Subthreshold) 영역 (VGS < Vth, 약 반전):
  ┌─────────────────────────────────────────────┐
  │  ID = I0·(W/L)·e^(VGS/n·VT)               │
  │  VT = kT/q = 26mV @300K                   │
  │  → 극저전력 회로, 누설전류 분석에 필수     │
  │  → 77K에서 subthreshold slope 급격히 감소  │
  └─────────────────────────────────────────────┘
```

## 1-C. Small-Signal 완전 등가회로

```
Small-Signal 모델 (고주파 포함):

       Cgd (게이트-드레인 커패시턴스, Miller 효과!)
      ┌────────┤├────────┐
      │                  │
G ───┤│Cgs             ro │├──── D
      │                  │
      └─── gm·vgs ──────┘
                S

  파라미터 수식:
  ┌──────────────────────────────────────────────────────┐
  │  gm   = ∂ID/∂VGS = 2ID/(VGS-Vth)                  │
  │       = √(2μnCox·W/L·ID)                           │
  │       단위: A/V = S(지멘스)                         │
  │                                                      │
  │  ro   = ∂VDS/∂ID = VA/ID = 1/(λ·ID)               │
  │       단위: Ω                                        │
  │                                                      │
  │  Cgs  = (2/3)·Cox·W·L + Cov   (채널+오버랩)        │
  │  Cgd  = Cov  (오버랩 커패시턴스만)                  │
  │  Csb, Cdb = 접합 커패시턴스 (역바이어스 의존)       │
  │                                                      │
  │  fT (전환주파수) = gm/(2π(Cgs+Cgd))               │
  │  → 회로 최대 동작 주파수 한계                       │
  └──────────────────────────────────────────────────────┘

  Miller 효과 (Cgd의 영향):
  ┌──────────────────────────────────────────────────────┐
  │  Cgd가 입력으로 반사되는 등가 커패시턴스:            │
  │  Cin_miller = Cgd·(1 + gm·RL)                      │
  │                                                      │
  │  열영상 CTIA에서 문제:                               │
  │  피드백 Cf도 동일 Miller 반사 → 입력 커패시턴스↑    │
  │  → TIA 대역폭 감소 → 프레임레이트 한계              │
  │  해결: Cascode 구조 → Cgd 효과 차단                │
  └──────────────────────────────────────────────────────┘

LTspice DC Operating Point 시뮬레이션 해석:

  .op 실행 후 확인 체크리스트:
  ┌──────────────────────────────────────────────────────┐
  │  ✓ VGS > Vth  (도통 확인)                          │
  │  ✓ VDS > VGS-Vth  (포화 확인)                     │
  │  ✓ ID 값이 설계 전류와 일치                        │
  │  ✓ 모든 MOSFET 동작점 출력 확인: .op 후 Ctrl+L    │
  │                                                      │
  │  CTIA M1 설계 목표:                                 │
  │  · VGS-Vth = 0.2~0.3V (적당한 overdrive)          │
  │  · ID = 1~10μA (픽셀 배열 전력 예산 내)            │
  │  · VDS = VDD/2 (최대 스윙 확보)                    │
  └──────────────────────────────────────────────────────┘
```

## 2-A. WHY : NETD와 TIA 노이즈의 직접 연결

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  NETD (Noise Equivalent Temperature Difference):                             │
│                                                                              │
│  NETD = Vn_rms / (dVout/dT)                                                 │
│                                                                              │
│  분자: 출력 노이즈 전압 (회로 설계로 결정!)                                   │
│  분모: 온도 1K 변화당 출력전압 변화 (검출기 + 광학 특성)                      │
│                                                                              │
│  G5-550HD 스펙: NETD < 25mK                                                 │
│  → Vn_rms를 극도로 낮춰야 함                                                 │
│                                                                              │
│  노이즈 기여 계층:                                                            │
│  ┌─────────────────────────────────────────────────────────────────────┐    │
│  │  광자 쇼트 노이즈 (피할 수 없음)        → SNR 상한 결정             │    │
│  │  Dark Current 쇼트 노이즈              → 77K 냉각으로 제거          │    │
│  │  kTC 리셋 노이즈                       → CDS로 제거                │    │
│  │  TIA 열잡음 (Rf, gm)                  → 회로 설계로 최소화         │    │
│  │  1/f 노이즈 (MOSFET 플리커)           → PMOS 입력단으로 감소       │    │
│  │  ADC 양자화 노이즈                    → 14bit로 감소               │    │
│  │  NUC 잔류 불균일성 (FPN)              → 교정 주기 최적화           │    │
│  └─────────────────────────────────────────────────────────────────────┘    │
└──────────────────────────────────────────────────────────────────────────────┘
```

│  1. Shot Noise (산탄 노이즈) — 광자 통계                                      │
│                                                                              │
│  In_shot² = 2q·(Iph + Id)·BW                                               │
│                                                                              │
│  77K에서: Id << Iph  → In_shot² ≈ 2q·Iph·BW                               │
│  300K에서: Id >> Iph → 쓸 수 없음! (냉각의 근본 이유)                       │
│                                                                              │
│  BW = 1/(2·Tint)  (적분 시 유효 대역폭)                                    │
│     = 1/(2×33ms) = 15Hz  for 30fps                                         │
│                                                                              │
│  → In_shot_rms = √(2×1.6e-19 × 1e-12 × 15) = 69aA  (아토암페어)          │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│  2. kTC Noise (리셋 노이즈)                                                   │
│                                                                              │
│  Vn_kTC = √(kT/Cf)                                                          │
│                                                                              │
│  T=77K, Cf=100fF:                                                           │
│  Vn_kTC = √(1.38e-23 × 77 / 100e-15) = 3.26mV  ← 크다!                   │
│                                                                              │
│  → CDS (Correlated Double Sampling)으로 제거:                               │
│  Vcds = Vsig - Vreset  → 두 측정의 공통 kTC 노이즈 상쇄                    │
│                                                                              │
│  CDS 후 남은 노이즈:                                                         │
│  Vn_after_CDS = √2 × Vn_shot (광자 쇼트만 남음)                            │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│  3. Thermal Noise (열잡음) — 저항 및 MOSFET                                  │
│                                                                              │
│  저항 R의 열잡음:                                                             │
│  Vn² = 4·k·T·R·BW                                                           │
│  In² = 4·k·T/R·BW   (등가 전류 노이즈)                                     │
│                                                                              │
│  MOSFET 채널 열잡음 (포화 영역):                                              │
│  Id_thermal² = 4·k·T·γ·gm·BW                                               │
│  γ = 2/3 (장채널), γ~2 (단채널 MOSFET)                                     │
│                                                                              │
│  입력 환산 전압 노이즈:                                                       │
│  Vn_in = √(4kTγ/gm)                                                        │
│  → gm 클수록 열잡음 작음  → 큰 W/L, 큰 ID 설계                            │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│  4. 1/f Noise (플리커 노이즈)                                                 │
│                                                                              │
│  Vn_1f² = K / (Cox·W·L·f)  [V²/Hz]                                        │
│                                                                              │
│  K = 플리커 노이즈 계수 (공정 파라미터)                                      │
│  PMOS: K_p < K_n  → PMOS 입력단이 유리                                      │
│                                                                              │
│  코너 주파수 fc:                                                             │
│  fc = gm·K / (4π·k·T·γ·Cox·W·L)                                           │
│  → fc 이하에서 1/f 노이즈 지배                                               │
│  → 열영상 픽셀 BW~15Hz → fc 이하면 1/f 문제                                │
│  → 해결: PMOS, 큰 게이트 면적(W·L↑)                                        │
└──────────────────────────────────────────────────────────────────────────────┘

노이즈 예산표 (CTIA 설계 실례):

  ┌────────────────────────────────────────────────────────────┐
  │  조건: Iph=1pA, Tint=33ms, Cf=100fF, T=77K              │
  ├───────────────────────────┬───────────────┬───────────────┤
  │  노이즈 소스               │  전류 노이즈   │  전압 노이즈  │
  │                            │  [aA rms]     │  [μV rms]    │
  ├───────────────────────────┼───────────────┼───────────────┤
  │  광자 쇼트 노이즈          │  69           │  22.8        │
  │  Dark Current (77K)       │  0.5          │  0.17        │
  │  MOSFET 열잡음 (gm=1μS)  │  45           │  14.9        │
  │  1/f 노이즈 (PMOS)        │  20           │  6.6         │
  │  ADC 양자화 (14bit)       │  -            │  1.2         │
  ├───────────────────────────┼───────────────┼───────────────┤
  │  합산 (RSS)               │  84           │  27.8        │
  ├───────────────────────────┼───────────────┼───────────────┤
  │  → NETD 환산              │               │  < 20mK ✓   │

## 4-B. WHAT : Feedback 이론 완전판

```
Feedback 시스템 신호 흐름도:

  r(s) ──►──[+]──►── A(s) ──►──────────►── y(s)
             │-                            │
             └──────────── β(s) ──────────┘

  폐루프 전달함수:
  T(s) = A(s) / (1 + A(s)·β(s))
  루프이득: L(s) = A(s)·β(s)

  안정 조건 (Nyquist/Bode):
  ┌──────────────────────────────────────────────────────────────────────────┐
  │  |L(jω)| = 1이 되는 주파수 ω₀에서                                       │
  │  ∠L(jω₀) > -180°   (PM > 0°)  → 안정                                  │
  │  ∠L(jω₀) = -180°   (PM = 0°)  → 발진 임계                             │
  │  ∠L(jω₀) < -180°   (PM < 0°)  → 불안정 (발진)                         │
  └──────────────────────────────────────────────────────────────────────────┘

Pole/Zero s-평면 완전 분석:

  s-평면:
  jω
   │        ×  좌반면 극점: 안정 (지수 감쇠)
   │     ×
   │        ↑
   │      exp(-σt)·sin(ωt)  σ > 0이면 감쇠
───┼────────────────── σ
   │  ○  우반면 극점: 불안정 (발산)
   │     ↑
   │   exp(+σt)  → ∞

  극점 위치와 시간 응답:

  s = -a ± jb (복소 켤레쌍):
  ┌──────────────────────────────────────────────────────────────────────────┐
  │   a↑, b=0  → 빠른 단조 감쇠 (Overdamped)                              │
  │   a=b      → 임계 감쇠 (Critically damped)                             │
  │   a<b      → 감쇠 진동 (Underdamped) → 오버슈트                       │
  │   a=0      → 순수 진동 (Marginally stable) = 발진 경계                │
  │   a<0      → 발산 (Unstable!)                                          │
  └──────────────────────────────────────────────────────────────────────────┘

Compensation 기법 4종:

  ① Miller 보상 (Two-stage Amp):
  ──────────────────────────────────────────────────────
          Cc
    ┌────┤├────┐
    │          │
  Stage1 ──► Stage2 ──► Vout
                         ↑CL

  Cc가 1st 극점 주파수 낮추고 → 2nd 극점 높임
  (Pole Splitting: p1↓, p2↑ → PM 개선)

  fp1_new ≈ 1/(2π·gm2·Cc·Rout1·Rout2)
  fp2_new ≈ gm2/(2π·CL)

  ② Lead Compensation (PD 보상):
  ──────────────────────────────────────────────────────
  Cc와 직렬 저항 Rc 삽입
  → fp2 위치에 영점 생성 → 위상 회복

  영점: fz = 1/(2π·Rc·Cc)
  → fz = fp2로 설정 → PM 대폭 개선

  ③ Cascode Compensation:
  ──────────────────────────────────────────────────────
  Cascode 구조로 Cgd 분리
  → Miller 효과 억제 → 내부 고주파 극점 제거

  ④ Nested Miller Compensation (3단 이상):
  ──────────────────────────────────────────────────────
  고이득 다단 회로용
  Cc1, Cc2 이중 피드백 → 안정성 확보
```

## 4-C. HOW : TEC PID + Stirling 냉각기 완전 제어

  │  FLIR G5-550HD 냉각 시스템:                                             │
  │                                                                         │
  │  1차 냉각: Stirling 냉각기  FPA → 77K 도달                            │
  │  Stirling 냉각기 = 역Carnot 사이클 열기관                              │
  │  · 소비전력: ~10W                                                      │
  │  · 냉각 시간: 5~10분 (cold-start)                                     │
  │  · 수명: ~10,000시간 (MTBF)                                           │
  │                                                                         │
  │  2차 온도 안정화: TEC + PID                                            │
  │  · Stirling 도달 온도 편차: ±2K                                       │
  │  · TEC로 미세 조정: ±0.05K 이내로 유지                                │
  └─────────────────────────────────────────────────────────────────────────┘

PID 완전 주파수 해석:

  연속시간 PID 전달함수:
  C(s) = Kp + Ki/s + Kd·s
       = Kd·(s² + (Kp/Kd)·s + Ki/Kd) / s

  영점 위치:
  z1,z2 = -(Kp ± √(Kp²-4Kd·Ki)) / (2Kd)
  → 영점을 플랜트 극점에 배치 → 극영점 상쇄로 응답 개선

  TEC 플랜트 모델:
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  TEC + FPA 열모델:                                                      │
  │                                                                         │
  │  G_plant(s) = K_tec / (τ_tec·s + 1)·(τ_fpa·s + 1)                   │
  │                                                                         │
  │  K_tec = 온도/전류 변환 이득 [K/A]                                    │
  │  τ_tec  = TEC 열 시정수 [s]  (통상 0.1~1s)                           │
  │  τ_fpa  = FPA 패키지 열 시정수 [s] (통상 0.01~0.1s)                  │
  │                                                                         │
  │  2개 극점 → Underdamped 위험 → Kd 필수                               │
  └─────────────────────────────────────────────────────────────────────────┘

이산시간 PID (DSP/FPGA 구현 실제):

  ┌─────────────────────────────────────────────────────────────────────────┐
  │  Bilinear Transform (Tustin 방법):                                      │
  │                                                                         │
  │  s = 2/Ts · (z-1)/(z+1)                                               │
  │                                                                         │
  │  이산 PID:                                                              │
  │  u[n] = u[n-1]                                                         │
  │       + (Kp + Ki·Ts/2 + Kd/Ts)·e[n]                                  │
  │       + (-Kp + Ki·Ts/2 - 2Kd/Ts)·e[n-1]                             │
  │       + (Kd/Ts)·e[n-2]                                                │
  │                                                                         │
  │  Ts = 10ms (100Hz 제어 주파수, TEC 응답보다 10배 빠름)                │
  └─────────────────────────────────────────────────────────────────────────┘

TEC PID 펌웨어 완전판:

```c
/* TEC PID Controller - UTuSAR IR Camera Firmware */
/* Target: STM32H7 or FPGA soft-core              */

#define T_SET_K      77.0f    /* 목표 온도 [K]        */
#define KP           3.2f     /* 비례 이득             */
#define KI           0.08f    /* 적분 이득             */
#define KD           1.5f     /* 미분 이득             */
#define TS           0.01f    /* 샘플링 주기 [s]       */
#define I_MAX        5.0f     /* TEC 최대 전류 [A]     */
#define I_MIN       -5.0f     /* TEC 최소 전류 [A]     */
#define INTEG_MAX    50.0f    /* Anti-windup 한계      */

typedef struct {
    float integral;
    float prev_err;
    float prev_err2;          /* 2차 미분 잡음 억제용  */
    float lpf_state;          /* 미분항 LPF 상태       */
} PID_State;

float tec_pid_update(PID_State *pid, float T_meas) {
    float err = T_SET_K - T_meas;

    /* 비례항 */
    float P_term = KP * err;

    /* 적분항 (Anti-windup: 포화 시 적분 정지) */
    pid->integral += err * TS;
    if      (pid->integral >  INTEG_MAX) pid->integral =  INTEG_MAX;
    else if (pid->integral < -INTEG_MAX) pid->integral = -INTEG_MAX;
    float I_term = KI * pid->integral;

    /* 미분항 (1차 LPF로 고주파 잡음 억제) */
    float raw_deriv = (err - pid->prev_err) / TS;
    float alpha = 0.1f;  /* LPF 계수: fc = α/(2π·Ts) */
    pid->lpf_state = alpha*raw_deriv + (1-alpha)*pid->lpf_state;
    float D_term = KD * pid->lpf_state;

    float u = P_term + I_term + D_term;

    /* 출력 포화 */
    if      (u >  I_MAX) u =  I_MAX;
    else if (u <  I_MIN) u =  I_MIN;

    pid->prev_err = err;
    return u;  /* TEC 전류 명령값 [A] */
}
```

  T(K)
   ↑
  77.0┤─────────────────────────────────── T_set
      │                   ╱‾‾‾‾‾‾ (약간 오버슈트 PM=60°)
      │                  ╱
  77.1┤─────────────────╱
      │                ╱
      │               ╱   Stirling 냉각기 도달 (~300K→77K 5분)
  150 ┤──────────────╱
      │             ╱
  300 ┼────────────
      └────┬────┬────┬────┬──────── t
          1분  2분  3분  5분

  수렴 후 온도 편차:
  Steady-state error = 0  (Ki > 0)
  Ripple = < ±0.05K  (D_term으로 진동 억제)
  PM = 60°에서 오버슈트 ≈ 8%  (77K × 8% = 77.08K → 허용범위)
```

## 5-A. WHY : FPGA RTL 설계가 열영상 실시간성의 핵심

```
┌──────────────────────────────────────────────────────────────────────────────┐

│                                                                              │

```verilog
// ============================================================
// Module: nuc_pipeline_v2
// Function: 2-point NUC with pipeline (5-stage)
// Target: Xilinx Zynq or Intel Cyclone V
// Clock: 200MHz processing clock
// ============================================================
module nuc_pipeline_v2 #(
    parameter DW = 14,          // 데이터 폭
    parameter GAIN_FRAC = 8     // 게인 고정소수점 소수부 비트
)(
    input  wire              clk,
    input  wire              rst_n,
    input  wire              pix_valid_in,
    input  wire [DW-1:0]     raw_pix,
    input  wire [DW-1:0]     offset_mem,   // 각 픽셀 오프셋 (BRAM)
    input  wire [DW-1:0]     gain_mem,     // 각 픽셀 게인 Q8.8 (BRAM)
    output reg               pix_valid_out,
    output reg  [DW-1:0]     nuc_pix
);
    // Pipeline registers
    reg signed [DW:0]        s1_sub;       // Stage1: offset 감산
    reg                      s1_valid;

    reg signed [DW:0]        s2_sub_q;     // Stage2: 게인 로드 대기
    reg        [DW-1:0]      s2_gain;
    reg                      s2_valid;

    reg signed [2*DW:0]      s3_mul;       // Stage3: 곱셈
    reg                      s3_valid;

    reg signed [2*DW:0]      s4_mul_q;    // Stage4: 곱셈 파이프 2nd
    reg                      s4_valid;

    // Stage 5 = output register (nuc_pix)

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            s1_sub <= 0; s1_valid <= 0;
            s2_sub_q <= 0; s2_gain <= 0; s2_valid <= 0;
            s3_mul <= 0; s3_valid <= 0;
            s4_mul_q <= 0; s4_valid <= 0;
            nuc_pix <= 0; pix_valid_out <= 0;
        end else begin
            // Stage 1: 감산
            s1_sub   <= $signed({1'b0, raw_pix})
                      - $signed({1'b0, offset_mem});
            s1_valid <= pix_valid_in;

            // Stage 2: 게인 래치
            s2_sub_q <= s1_sub;
            s2_gain  <= gain_mem;
            s2_valid <= s1_valid;

            // Stage 3: 곱셈 하위
            s3_mul   <= s2_sub_q * $signed({1'b0, s2_gain});
            s3_valid <= s2_valid;

            // Stage 4: 곱셈 상위 래치 (DSP 타이밍)
            s4_mul_q <= s3_mul;
            s4_valid <= s3_valid;

            // Stage 5: 정규화 + 클리핑
            pix_valid_out <= s4_valid;
            if (s4_mul_q[2*DW] == 1'b1)       // 음수 → 0으로 클리핑
                nuc_pix <= 0;
            else if (|s4_mul_q[2*DW-1:DW+GAIN_FRAC])  // 오버플로우
                nuc_pix <= {DW{1'b1}};
            else
                nuc_pix <= s4_mul_q[DW+GAIN_FRAC-1:GAIN_FRAC];
        end
    end
endmodule
```

```verilog
// ============================================================
// Module: nuc_shutter_fsm
// Function: 자동 NUC 교정 (N 프레임마다 또는 온도 드리프트시)
// ============================================================
module nuc_shutter_fsm #(
    parameter NUC_PERIOD = 300  // 300 프레임 = 10초 주기
)(
    input  wire        clk,
    input  wire        rst_n,
    input  wire        frame_end,         // 프레임 완료 펄스
    input  wire        temp_drift_alarm,  // 온도 드리프트 > 0.5K
    output reg         shutter_close,     // 셔터 닫기 명령
    output reg         nuc_capture_en,    // NUC 기준 프레임 캡처
    output reg         nuc_calc_en,       // NUC 계수 계산
    output reg         normal_mode        // 정상 영상 출력 중
);
    localparam IDLE      = 3'd0;
    localparam PRE_SHUT  = 3'd1;  // 셔터 닫기 전 안정화 2프레임
    localparam SHUTTING  = 3'd2;  // 셔터 완전 닫힘 대기 3프레임
    localparam CAPTURING = 3'd3;  // 기준 프레임 캡처
    localparam CALC      = 3'd4;  // 계수 계산 (2프레임 여유)
    localparam OPEN_SHUT = 3'd5;  // 셔터 열기

    reg [2:0]  state;
    reg [8:0]  frame_cnt;
    reg [2:0]  wait_cnt;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            state         <= IDLE;
            frame_cnt     <= 0;
            shutter_close <= 0;
            nuc_capture_en<= 0;
            nuc_calc_en   <= 0;
            normal_mode   <= 1;
        end else begin
            case (state)
                IDLE: begin
                    normal_mode <= 1;
                    if (frame_end) frame_cnt <= frame_cnt + 1;
                    if (frame_cnt >= NUC_PERIOD || temp_drift_alarm) begin
                        frame_cnt <= 0;
                        state     <= PRE_SHUT;
                        wait_cnt  <= 0;
                    end
                end
                PRE_SHUT: begin
                    // 셔터 닫기 명령 전 2프레임 준비
                    if (frame_end) begin
                        if (wait_cnt >= 2) begin
                            shutter_close <= 1;
                            normal_mode   <= 0;
                            state         <= SHUTTING;
                            wait_cnt      <= 0;
                        end else wait_cnt <= wait_cnt + 1;
                    end
                end
                SHUTTING: begin
                    // 셔터 완전 닫힘까지 3프레임 대기
                    if (frame_end) begin
                        if (wait_cnt >= 3) begin
                            state    <= CAPTURING;
                            wait_cnt <= 0;
                        end else wait_cnt <= wait_cnt + 1;
                    end
                end
                CAPTURING: begin
                    nuc_capture_en <= 1;
                    if (frame_end) begin
                        nuc_capture_en <= 0;
                        state          <= CALC;
                        wait_cnt       <= 0;
                    end
                end
                CALC: begin
                    nuc_calc_en <= 1;
                    if (frame_end) begin
                        if (wait_cnt >= 2) begin
                            nuc_calc_en   <= 0;
                            shutter_close <= 0;
                            state         <= OPEN_SHUT;
                            wait_cnt      <= 0;
                        end else wait_cnt <= wait_cnt + 1;
                    end
                end
                OPEN_SHUT: begin
                    // 셔터 열린 후 안정화 3프레임
                    if (frame_end) begin
                        if (wait_cnt >= 3) begin
                            normal_mode <= 1;
                            state       <= IDLE;
                        end else wait_cnt <= wait_cnt + 1;
                    end
                end
            endcase
        end
    end
endmodule

## 6-A. 타이밍 분석 완전판

```
STA (Static Timing Analysis) 완전 경로 분석:

  발신 FF → 조합논리 → 수신 FF

  ┌────────────────────────────────────────────────────────────────────────────┐
  │  Setup Timing (데이터가 클럭 엣지 전에 안정화):                            │
  │                                                                            │
  │  CLK_src ─────────────────────────────────┐ (클럭 소스)                  │
  │                                            │                               │
  │  CLK_launch ──────────────────┐           ↓ 클럭 전파 tclk_src→launch    │
  │                               │ (발신 FF 클럭)                             │
  │                               ↓                                            │
  │  Q_launch  ────────────────────────────── →                               │
  │  (tco 후 출력)              tco            →  조합논리 경로               │
  │                                            → tpd                          │
  │                                             →                             │
  │  CLK_capture ──────────────────────────────────────┐ (수신 FF 클럭)      │
  │                                                     │ tclk_src→capture    │
  │                                                     ↓                     │
  │  D_capture  ─────────────────────────────────────→ tsu 필요              │
  │                                                                            │
  │  Setup 제약:                                                               │
  │  tco + tpd + tsu ≤ T_clk + tclk_src→capture - tclk_src→launch           │
  │  tco + tpd + tsu ≤ T_clk + T_skew                                        │
  │                                                                            │
  │  (T_skew > 0이면 수신 FF 클럭이 더 늦어 = 유리)                          │
  │  (T_skew < 0이면 불리 → Clock Tree Synthesis로 최소화)                   │
  └────────────────────────────────────────────────────────────────────────────┘

  ┌────────────────────────────────────────────────────────────────────────────┐
  │  Hold Timing (클럭 엣지 직후 데이터 유지):                                 │
  │                                                                            │
  │  Hold 제약:                                                                │
  │  tco_min + tpd_min ≥ th + T_skew                                         │
  │                                                                            │
  │  (짧은 경로 = Hold violation 위험)                                        │
  │  → 조합논리 없는 직접 연결에서 자주 발생                                   │
  │  → 해결: 버퍼 삽입 (tpd_min 증가)                                        │
  └────────────────────────────────────────────────────────────────────────────┘

Critical Path 시각화 (NUC 14bit 곱셈기):

  A[13:0] ──┐
            ├── [14×14 곱셈기] ──────────────────────────────────────► S[27:0]
  B[13:0] ──┘
             └── Carry 전파 체인 (가장 긴 경로)

  경로 분석:
  ┌──────────────────────────────────────────────────────────────────┐
  │  14×14 Wallace Tree 곱셈기 (FPGA DSP 블럭 사용 시):            │
  │  tpd = tDSP = 3ns @200MHz Cyclone V                            │
  │  → 하나의 클럭 주기(5ns) 안에 완료 ✓                          │
  │                                                                  │
  │  FPGA DSP 없이 LUT 구현 시:                                    │
  │  tpd = 14×tFA = 14×1ns = 14ns → 200MHz 불가                   │
  │  → 파이프라인 4단계 필요 → tpd/stage = 3.5ns ✓               │
  └──────────────────────────────────────────────────────────────────┘

멀티클럭 도메인 처리 (CDC - Clock Domain Crossing):

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  열영상 FPGA 클럭 도메인:                                                 │
  │                                                                          │
  │  도메인 A: 20MHz (pixel_clk) ─── FPA 인터페이스                        │
  │  도메인 B: 200MHz (proc_clk) ─── 영상처리 파이프라인                   │

## 7-C. 임피던스 제어 배선 (Signal Integrity 핵심)

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  WHY : 임피던스 불연속 → 신호 반사 → LVDS 오류                              │
│                                                                              │
│  반사 계수: Γ = (ZL - Z0) / (ZL + Z0)                                      │
│  ZL = 부하 임피던스, Z0 = 전송선로 특성 임피던스                            │
│                                                                              │
│  ZL = Z0 → Γ = 0 → 반사 없음 (이상적)                                     │
│  ZL ≠ Z0 → 반사 발생 → 신호 왜곡                                          │
└──────────────────────────────────────────────────────────────────────────────┘

임피던스 계산 (마이크로스트립):

  단면도:
  ─────── W (선폭) ──────
  ═══════════════════════  도체 (두께 t)
  ─────────────────────── 유전체 (높이 H, εr)
  ━━━━━━━━━━━━━━━━━━━━━━━  GND 플레인

  특성 임피던스 Z0 (마이크로스트립):
  ┌──────────────────────────────────────────────────────────────────────────┐
  │  Z0 = (87/√(εr+1.41)) × ln(5.98H / (0.8W + t))  [Ω]                  │
  │                                                                          │
  │  예: FR4 εr=4.4, H=4mil, t=1.4mil, W=7.5mil                           │
  │  Z0 = (87/√5.41) × ln(5.98×4/(0.8×7.5+1.4))                          │
  │     = 37.4 × ln(23.92/7.4)                                             │
  │     = 37.4 × 1.17 = 43.8Ω  ← 50Ω 목표면 W 조정                      │
  └──────────────────────────────────────────────────────────────────────────┘

  임피던스 조건별 배선 설계:

  ┌────────────────────┬────────────────┬────────────────────────────────────┐
  │  신호 종류          │  목표 임피던스  │  배선 규칙                        │
  ├────────────────────┼────────────────┼────────────────────────────────────┤
  │  단일 종단 (디지털) │  50Ω ±10%    │  GND 플레인 위, 폭 W 계산         │
  │  LVDS 차동쌍        │  100Ω 차동    │  간격 S 제어, 쌍 길이 매칭        │
  │  DDR SDRAM          │  40~60Ω       │  플라이바이 토폴로지               │
  │  GigE (1000BASE-T) │  100Ω 차동    │  임피던스 + 스큐 < 5ps            │
  │  전원 배선           │  임피던스 무관 │  최대 폭, 비아 최소화             │
  └────────────────────┴────────────────┴────────────────────────────────────┘

LVDS (Low Voltage Differential Signaling) 배선 완전 규칙:

  LVDS 기본 구조:
              100Ω 종단
  TX+ ─────────────────────────►── RX+
        ∪∪∪∪∪∪∪∪∪∪∪∪∪∪∪∪∪         │100Ω│
  TX- ─────────────────────────►── RX-
              쌍 배선 (차동)

  열영상 LVDS (FPA → FPGA) 배선 규칙:
  ┌──────────────────────────────────────────────────────────────────────────┐
  │  ① 쌍 간격 (S): S = 5~8mil  (쌍 결합 강화, 외부 노이즈 내성↑)         │
  │  ② 쌍 내 길이 매칭: ΔL < 5mil  (스큐 < 5ps @200Mbps)                 │
  │  ③ 쌍 사이 간격: 쌍과 쌍 사이 > 3×S  (크로스토크 방지)               │
  │  ④ 90° 코너 금지: 45° 또는 아크 사용  (임피던스 불연속 방지)          │
  │  ⑤ 비아 최소화: 비아 1개당 ~0.5nH 인덕턴스 추가 → 반사               │
  │  ⑥ 비아 사용 시: 차동쌍 비아 동시 배치 (대칭 유지)                    │
  │  ⑦ 레퍼런스 플레인 연속성: LVDS 경로 하단 GND 플레인 끊어짐 금지      │
  │                                                                          │
  │  LVDS 배선 단면:                                                        │
  │                                                                          │
  │  L1: ══════  ══════  (LVDS+, LVDS-)  S=6mil  W=5mil                  │
  │                ↕H=4mil                                                  │
  │  L2: ████████████████████████████  (GND 플레인 연속)                  │
  │                                                                          │
  │  Z_diff = 2 × Z0_single × (1 - 0.347·e^(-2.9·S/H))                   │
  │         ≈ 2 × 55Ω × 0.91 = 100Ω ✓                                    │
  └──────────────────────────────────────────────────────────────────────────┘

DDR 메모리 배선 (FPGA ↔ DDR4 SDRAM):

  플라이바이 토폴로지:
  ┌──────────────────────────────────────────────────────────────────────────┐
  │  FPGA ──►── DRAM1 ──►── DRAM2 ──►── DRAM3 ──►── 종단저항              │
  │  (T자형 분기 금지! → 반사로 eye diagram 닫힘)                          │
  │                                                                          │
  │  Address/Command: 플라이바이                                            │
  │  Data (DQ, DQS): 포인트-투-포인트 (점대점)                             │
  │  Clock (CK+/-): 차동쌍, 모든 DQ 길이 기준선                           │
  │                                                                          │
  │  길이 매칭:                                                              │
  │  DQS ↔ DQ: ±10mil  (스큐 < 10ps @2400Mbps)                           │
  │  CK ↔ ADD: ±50mil  (여유 있음)                                         │
  └──────────────────────────────────────────────────────────────────────────┘
```

## 7-D. PDN (Power Delivery Network) 완전 설계

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  WHY : PDN 불량이 열영상 영상 품질에 직접 영향                               │
│                                                                              │
│  FPGA 클럭 엣지 발생 시 순간 전류 스파이크:                                  │
│  ΔI = C_total × ΔV/Δt                                                      │
│     = 100nF × 0.5V/1ns = 50A  (!)                                         │
│                                                                              │
│  → PDN 임피던스 Z_pdn에서 전압 드롭:                                        │
│  ΔV = Z_pdn × ΔI                                                           │
│  Z_pdn = 0.001Ω → ΔV = 50mV  (허용)                                      │
│  Z_pdn = 0.01Ω  → ΔV = 500mV (FPGA 오작동!)                              │
└──────────────────────────────────────────────────────────────────────────────┘

PDN 임피던스 주파수 응답:

  Z_pdn(f)│
    (Ω)   │
    0.1   │  ╲ 벌크 커패시터 (탄탈/MLCC 100μF)
          │   ╲  fc1=1kHz
   0.01   │    ╲_____
          │           ╲ 세라믹 MLCC 10μF
          │            ╲  fc2=1MHz
  0.001   │             ╲___________
          │                         ╲ MLCC 100nF
          │                          ╲  fc3=10MHz
  0.0001  │                           ╲__________
          │                                       ╲ FPGA 내장 캐패시터
          └──────────────────────────────────────── f(Hz)
              1K    10K   100K   1M    10M   100M  1G

  목표: Z_pdn < Ztarget = ΔV_target / ΔI_max
  Ztarget = 50mV / 50A = 0.001Ω  (1mΩ!)
  → 여러 값의 커패시터 병렬 배치 필수

디커플링 커패시터 배치 전략:

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  3단계 디커플링 (벌크 → 중간 → 로컬):                                   │
  │                                                                          │
  │  1단계 벌크 (100μF~1000μF):                                            │
  │  · 위치: 보드 가장자리, VRM(전압 레귤레이터) 근처                      │
  │  · 역할: 수백 kHz 이하 저주파 노이즈 제거                              │
  │  · 종류: 폴리머 탄탈, 전해 커패시터                                    │
  │                                                                          │
  │  2단계 중간 (1μF~10μF):                                                │
  │  · 위치: FPGA 패키지 근처 (5mm 이내)                                  │
  │  · 역할: 수 MHz 범위 노이즈                                            │
  │  · 종류: X5R/X7R MLCC 0402/0603                                       │
  │                                                                          │
  │  3단계 로컬 (100nF):                                                   │
  │  · 위치: 각 VDD 핀 바로 옆 (2mm 이내), EVERY VDD PIN마다              │
  │  · 역할: 수십~수백 MHz 고주파 스파이크                                 │
  │  · 종류: C0G/NP0 MLCC 0201/0402 (자기 공명주파수 높음)               │
  │                                                                          │
  │  비아 배치:                                                             │
  │  커패시터 패드 바로 옆에 GND 비아, VDD 비아 → 인덕턴스 최소화         │
  │  비아 인덕턴스: L_via ≈ 0.5nH × (보드두께/1mm)                       │
  └──────────────────────────────────────────────────────────────────────────┘

PDN 비아 설계:

  FPGA VDD 핀 → 비아 → 전원 플레인 경로:

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  FPGA BGA 패키지 (예: Xilinx Zynq XC7Z045)                            │
  │                                                                          │
  │  ● ● ● ● ● ● ● ● ● ● ● ●   BGA 볼 배열 (0.8mm 피치)               │
  │  ● V V V V V V V V V V ●   V = VDD 핀                                │
  │  ● V G V G V G V G V V ●   G = GND 핀                                │
  │  ● V G V G V G V G V V ●                                              │
  │  ● V V V V V V V V V V ●                                              │
  │  ● ● ● ● ● ● ● ● ● ● ● ●                                              │
  │                                                                          │
  │  각 VDD 핀: 패드 → L1 배선 → 비아(0.2mm 드릴) → L3 전원 플레인       │
  │  각 GND 핀: 패드 → 비아(0.2mm 드릴) → L2 GND 플레인                  │
  │                                                                          │
  │  비아 전류 용량: I = 0.048 × ΔT^0.44 × d^0.725 × t^0.725             │
  │  (d=드릴직경mm, t=두께mm, ΔT=온도상승°C)                              │
  │  0.2mm 드릴 비아 → ~0.5A → 다중 비아 필요 (고전류 경로)              │
  └──────────────────────────────────────────────────────────────────────────┘
```

## 7-E. EMC 설계 (군용 MIL-STD-461 대응)

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  WHY : 방공 시스템은 MIL-STD-461 EMC 시험 필수                               │
│                                                                              │
│  적용 시험 항목 (G5-550HD 영상처리 보드):                                    │
│  · CE101: 전원선 전도 방사 (25Hz~10kHz)                                   │
│  · CE102: 전원선 전도 방사 (10kHz~10MHz)                                  │

│  · CS101: 전원선 전도 내성                                                 │

EMC PCB 설계 기법:

  ① 3W 규칙 (크로스토크 방지):
  ┌──────────────────────────────────────────────────────────────────────────┐
  │  고속 신호 배선 사이 간격 > 3×W  (W = 배선 폭)                        │
  │                                                                          │
  │  ══════   ──── 최소 3W 간격 ────   ══════                             │
  │  signal A                           signal B                            │
  │                                                                          │
  │  3W 미달 시 용량성 크로스토크:                                          │
  │  Vxt = Cm/(Cm+Cf) × Vsrc  (Cm = 상호 커패시턴스)                      │

## 7-F. 열 설계 (Thermal Design)

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  WHY : FPGA 과열 = 타이밍 위반 = 영상 오류                                   │
│                                                                              │
│  FPGA 접합부 온도 (Tj) 제약:                                                 │
│  Tj = Ta + P × Rθja                                                         │
│  Ta = 주변 온도 (군용: -40°C ~ +85°C)                                      │
│  P  = FPGA 소비전력 (예: 5W)                                               │
│  Rθja = 접합부-주변 열저항 (방열판 없이 ~20°C/W)                           │
│                                                                              │
│  Tj = 85 + 5 × 20 = 185°C → 절대 최대값(125°C) 초과!                     │
│  → 방열판 필수: Rθja → 2~5°C/W로 줄여야 함                               │
└──────────────────────────────────────────────────────────────────────────────┘

열 저항 네트워크:

  FPGA 다이 → 패키지 → PCB → 방열판 → 공기

  Tj ─── Rθjc ─── Tc ─── Rθcs ─── Ts ─── Rθsa ─── Ta
  (접합) (접합-케이스) (케이스) (케이스-방열판) (방열판) (방열판-공기) (공기)

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  전체 열저항: Rθja = Rθjc + Rθcs + Rθsa                               │
  │                                                                          │
  │  목표 Rθsa (방열판):                                                    │
  │  Rθsa = (Tj_max - Ta_max)/P - Rθjc - Rθcs                             │

  │                                                                          │

# CH.9  퀵레퍼런스 치트시트 — UTuSAR 연구원 일일 사용

```

[아날로그 핵심 수식]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MOSFET (포화):   ID = (μnCox·W/2L)(VGS-Vth)²(1+λVDS)
                 gm = 2ID/(VGS-Vth) = √(2μnCox·W/L·ID)
                 ro = VA/ID

CTIA 출력:       Vout = Iph × Tint / Cf
CTIA 대역폭:     BW = gm/(2π·Cf)  (실제: gm of inverter)
TIA 대역폭:      BW = 1/(2π·Rf·Cf)

Shot Noise:      In² = 2q·I·BW
Thermal (R):     Vn² = 4kTR·BW
MOSFET Channel:  Id² = 4kTγgm·BW  (γ=2/3 장채널)
1/f Noise:       Vn² = K/(Cox·WL·f)
kTC Noise:       Vn = √(kT/Cf)  → CDS로 제거

Diff Amp:        Ad = gm·Rout,  Ac = -Rout/(2Rss)
CMRR:            = 2gm²·ro·Rss
Phase Margin:    PM = 180° + ∠A(jω₀)  at |A(jω₀)|=1
Miller Cc:       fp1↓ = 1/(2π·gm2·Cc·R1·R2),  fp2↑ = gm2/(2π·CL)

PID:             u = Kp·e + Ki·∫e·dt + Kd·de/dt
이산 PID:        u[n] = u[n-1] + c0·e[n] + c1·e[n-1] + c2·e[n-2]

NETD:            = Vn_rms / (dVout/dT)  목표: < 25mK

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[디지털 핵심 수식]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

픽셀 클럭:   f_pix = W × H × fps × 오버헤드 = 640×512×30×1.2 ≈ 11.8MHz
RCA 지연:    tpd = N × tFA
CLA 이득:    tpd ≈ O(log₄N) × tFA  (4비트 블록 기준)
Setup 제약:  tco + tpd + tsu ≤ T_clk + T_skew_benefit
Hold 제약:   tco_min + tpd_min ≥ th + T_skew_penalty
동적전력:    P = α × C × VDD² × f
GBW:         = Gm/(2π·CL)
