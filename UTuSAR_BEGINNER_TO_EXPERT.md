## 🟡 중급: 흑체복사 법칙

```
  플랑크 법칙 (물체의 복사 스펙트럼):

  B(λ,T) = (2hc²/λ⁵) × 1/(exp(hc/λkT) - 1)

  빈의 변위 법칙 (최대 복사 파장):
  λ_max = b/T   (b = 2898 μm·K)

  드론(T=320K):  λ_max = 2898/320 = 9.1μm  (LWIR)
  드론 엔진(T=400K): λ_max = 2898/400 = 7.2μm
  → 엔진열은 MWIR 3~5μm에서도 강하게 방출 → G5-550HD로 탐지!

  슈테판-볼츠만 법칙 (총 복사 전력):
  M = ε × σ × T⁴   [W/m²]
  σ = 5.67×10⁻⁸ W/m²·K⁴

  드론과 배경의 온도 대비:
  ┌──────────────────────────────────────────────────────────────────────────┐
  │  드론 모터: T₁ = 350K  →  M₁ = 0.9 × 5.67e-8 × 350⁴ = 854 W/m²    │
  │  배경 하늘: T₂ = 250K  →  M₂ = 0.9 × 5.67e-8 × 250⁴ = 221 W/m²    │
  │  대비:     ΔM = 633 W/m²  →  이 차이를 FPA가 탐지                    │
  └──────────────────────────────────────────────────────────────────────────┘
```

## 🔴 고급: NETD 계산 체인

```
  드론 탐지 시나리오 수치 계산 (100m 거리):

  ① 드론 → FPA 픽셀에 도달하는 광자 플럭스:
     Φ = ΔM × A_pixel × τ_lens × τ_atm / (π × R²)
       ≈ 633 × (15e-6)² × 0.9 × 0.95 / (π × 100²)
       ≈ 4.08×10⁻¹³ W/pixel

  ② 광자→전자 변환:
     E_photon = hc/λ = 6.626e-34 × 3e8 / 4e-6 = 4.97e-20 J
     Φ_photon = 4.08e-13 / 4.97e-20 = 8.2×10⁶ 광자/s/pixel

  ③ 광전류 생성:
     Iph = QE × q × Φ = 0.8 × 1.6e-19 × 8.2e6 = 1.05e-12 A ≈ 1pA

  ④ CTIA 출력전압:
     Vout = Iph × Tint / Cf = 1e-12 × 33e-3 / 100e-15 = 0.33V

  ⑤ 14bit ADC 디지털값:
     ADC = 0.33V / (3.3V/16384) = 1638 LSB  ← 화면 중간 밝기 드론 열점!

  ⑥ NETD 계산:
     dVout/dT = Iph/Cf × dIph/dT × 1/Iph × Tint
              ≈ 3mV/K  (대략적 값)
     NETD = Vn_rms / (dVout/dT)
     Vn_rms = √(Shot² + Thermal² + 1/f²) ≈ 0.07mV
     NETD = 0.07mV / 3mV/K = 23mK < 25mK ✓
```

## 🔴 고급: 단계별 설계 예시

```

  ID = 5μA, Vth = 0.5V, μnCox = 200μA/V², 요구 gm = 1mA/V

  gm = √(2·μnCox·W/L·ID)
  1e-3 = √(2 × 200e-6 × W/L × 5e-6)
  W/L = (1e-3)² / (2 × 200e-6 × 5e-6) = 500

  VGS = Vth + √(2ID/(μnCox·W/L))
      = 0.5 + √(2×5e-6/(200e-6×500)) = 0.5 + 0.1 = 0.6V ✓

  Step 3. LTspice 검증:
  .op 실행 → ID=5μA, VDS>VGS-Vth=0.1V → 포화 확인 ✓

## 🔴 고급: 이산 PID + Anti-windup 코드

```

       + (-Kp + Ki·Ts/2 - 2Kd/Ts) × e[n-1]
       + (Kd/Ts) × e[n-2]

  코드 (C, STM32H743):
  ┌──────────────────────────────────────────────────────────────────────────┐
  │  typedef struct {                                                       │
  │    float Kp, Ki, Kd, Ts;                                              │
  │    float integral, prev_err, prev_prev_err;                           │
  │    float lpf_state;   // 미분항 LPF                                   │
  │    float out_max, out_min;                                            │
  │  } PID_t;                                                              │
  │                                                                         │
  │  float PID_update(PID_t *p, float setpoint, float measured) {         │
  │    float e = setpoint - measured;                                     │
  │                                                                         │
  │    // 비례항                                                           │
  │    float P = p->Kp * e;                                               │
  │                                                                         │
  │    // 적분항 + Anti-windup (조건부 적분)                              │
  │    float u_raw = P + p->Ki * p->integral;                            │
  │    if ((u_raw < p->out_max && u_raw > p->out_min) ||                │
  │        (u_raw >= p->out_max && e < 0) ||                            │
  │        (u_raw <= p->out_min && e > 0))                              │
  │      p->integral += e * p->Ts;                                        │
  │    float I = p->Ki * p->integral;                                     │
  │                                                                         │
  │    // 미분항 + LPF (노이즈 억제)                                      │
  │    float raw_d = (e - p->prev_err) / p->Ts;                          │
  │    float alpha = 0.1f;  // fc = alpha/(2π·Ts)                        │
  │    p->lpf_state = alpha*raw_d + (1-alpha)*p->lpf_state;              │
  │    float D = p->Kd * p->lpf_state;                                   │
  │                                                                         │
  │    float u = P + I + D;                                               │
  │    u = fmaxf(p->out_min, fminf(p->out_max, u));  // 포화             │
  │                                                                         │
  │    p->prev_err = e;                                                   │
  │    return u;                                                           │
  │  }                                                                     │
  └──────────────────────────────────────────────────────────────────────────┘
```

## 🟡 중급: FMCW 신호 + Range-Doppler Map

```
  📊 FMCW 송수신 신호:

  주파수│  ╱╲         ╱╲         ← 송신(TX): 9.1→9.5GHz 반복
  (GHz) │ ╱  ╲       ╱  ╲
  9.5   │╱    ╲     ╱    ╲
        │      ╲   ╱      ╲
  9.1   │       ╲ ╱        ╲
        │         ╱  ╲       ╱   ← 수신(RX): 지연 τ=2R/c 후 도착
        │        ╱    ╲     ╱
        └──────────────────────── t(ms)
                   ↕ τ
            Beat = f_TX - f_RX  ← 이 차이가 거리 정보!

  Beat 주파수로 거리 계산:
  ┌──────────────────────────────────────────────────────────────────────────┐
  │  f_beat = BW/T_chirp × 2R/c                                            │
  │                                                                          │
  │  R = f_beat × c × T_chirp / (2 × BW)                                  │
  │                                                                          │
  │  R40i 파라미터:  BW=400MHz, T_chirp=1ms                               │
  │  f_beat=100kHz → R = 100e3 × 3e8 × 1e-3 / (2×400e6) = 37.5m          │
  │  거리 분해능: δR = c/(2×BW) = 3e8/(2×400e6) = 0.375m                 │
  └──────────────────────────────────────────────────────────────────────────┘

  📊 Range-Doppler Map (2D FFT 결과):

  속도│     (단위: m/s)
  [m/s]│
  +50  ┤                        ● (접근하는 드론)
  +20  ┤                   ●
   0   ┼─────────────██████────────────────  ← 클러터 (정지 물체)
  -20  ┤         ●
  -50  ┤   ● (멀어지는 드론)
       └─────────────────────────────────── 거리 [m]
            100  200  300  500  800  1000

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  CFAR 탐지 과정:                                                         │
  │  각 셀 주변 N개 셀의 평균 파워 계산 → T = μ + k×σ                     │
  │  현재 셀 파워 > T  → 표적 탐지!                                        │
  │                                                                          │
  │  OS-CFAR (방공포대 권장):                                               │
  │  주변 셀 파워 정렬 → k번째 값 × α 사용                                 │
  │  WHY: 건물·나무 불균일 클러터에 CA-CFAR보다 강건                       │
